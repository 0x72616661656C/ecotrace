# EcoTrace

Ferramenta experimental para segmentação de cobertura florestal em imagens multiespectrais Sentinel-2, com U-Net, Attention U-Net e visualização de incerteza por Monte Carlo Dropout.

## Estrutura

- `models/`: arquiteturas, notebook de treinamento e dependências de pesquisa;
- `web/`: API FastAPI e interface React/Vite.

Dados de treinamento, checkpoints, imagens extraídas, caches, ambientes e builds não são versionados. Veja os READMEs de cada pasta para instalar e configurar o projeto.
